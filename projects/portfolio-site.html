Why Vanilla?

In an age of React, Vue, and countless build tools, I chose to build this portfolio with plain HTML, CSS, and JavaScript. Why? Because for a static portfolio site, simplicity wins.

  • Zero build step means instant deployment to GitHub Pages
  • No JavaScript framework overhead—faster load times
  • Easy to maintain and update without dependency management
  • Demonstrates fundamental web skills, not just framework knowledge

The right tool for the job: Frameworks are powerful, but not every project needs one. Sometimes the simplest solution is the best one.

Design Philosophy

The dark, atmospheric aesthetic with purple accents was chosen to reflect my identity as a game developer while maintaining professional credibility for general software engineering roles. Every visual decision serves a purpose.

Consistent design system with CSS custom properties

  • CSS custom properties for easy theming and consistency
  • Mobile-first responsive design with fluid typography
  • Subtle animations that enhance without distracting
  • High contrast ratios for accessibility

Performance Optimization

A portfolio site needs to load fast—first impressions matter. I focused on core web vitals and achieved 90+ scores across all Lighthouse categories.

  • Minimal external dependencies (just Google Fonts)
  • CSS animations instead of JavaScript where possible
  • Intersection Observer for efficient scroll-triggered animations
  • Passive event listeners for scroll handlers
  • Prefers-reduced-motion support for accessibility

Accessibility

Building an accessible site isn't just about compliance—it's about reaching everyone. This site follows WCAG guidelines and works with assistive technologies.

  • Semantic HTML5 elements (nav, main, section, article)
  • Proper heading hierarchy
  • Keyboard navigation support
  • ARIA labels for interactive elements
  • Respects reduced-motion preferences
