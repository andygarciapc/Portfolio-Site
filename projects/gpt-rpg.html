GPT-RPG

A Unity-based role-playing game where GPT-3 serves as a dynamic Dungeon Master, generating narrative, dialogue, and quest outcomes at runtime for truly emergent gameplay.

Unity Game
~60% Latency Reduction
C# + GPT-3 API

The Vision

Traditional RPGs are limited by pre-written dialogue and scripted quest outcomes. I wanted to explore what happens when you put an AI in the dungeon master's chair— could a language model generate compelling, contextual narrative in real-time?

AI-generated dialogue responding to player choices

The Architecture

The core challenge was integrating an external API into a real-time game loop without breaking the player experience. API calls are inherently slow and unpredictable—not great for games that need to feel responsive.

  • Designed an async request queue to handle API calls without blocking the main thread
  • Implemented context management to maintain narrative coherence across sessions
  • Built a prompt engineering system that provided GPT with game state and constraints
  • Created fallback responses for when API calls failed or timed out

The key optimization: By carefully managing request frequency and optimizing token usage in prompts, I reduced perceived latency by approximately 60% while maintaining narrative quality.

How It Works

When a player interacts with an NPC or reaches a decision point, the game constructs a prompt containing:

  • Current game state (location, inventory, quest progress)
  • NPC personality and background
  • Recent conversation history
  • Constraints to keep responses game-appropriate

GPT then generates a contextually appropriate response that the game parses and presents to the player. Quest outcomes, rewards, and story branches all emerge from the AI's responses.
